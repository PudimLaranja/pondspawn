# Pondspawn

This project is a mod for the game Minecraft. It adds a new "Origin" to the origins mod, a origin is a kinda of player species that changes the way you play the game, the origins mod is originally made by [Apace100](https://github.com/apace100/origins-fabric). This mod only adds a new origin to this existing mod.
The origin this mods adds is called Pondspawn, it is a humanoid frog, that can use its unique physiology to do things humans can't.
Their Powers include:

- Tongue Hook: you can use your tongue as a grappling hook, pushing yourself towards entities or blocks or swinging from then to get to difficulty places with ease.
- High jump: You can jump one block more than a normal human with the total of two blocks.
- Super jump: You can charge your jump by holding crouch and then perform a super jump horizontally or vertically.

Esse projeto é um mod para o jogo Minecraft. Ele adiciona uma nove "Origem" para o mod de origens, uma origem é uma espécie diferente que o jogador pode ser, mudando o jeito que o jogador experiencia o jogo. O Mod de Origens é feito originalmente por [Apace100](https://github.com/apace100/origins-fabric). Esse mod apenas adiciona uma nova origem para esse mod.
A origem que esse mod adiciona se chama Pondspawn, ela é um sapo humanoide, que consegue usar sua fisiologia única para realizar feitos que humanos não podem.
O seus poderem incluem:

- Gancho de lingua: Você pode usar sua lingua para lançar um gancho que agarra em blocos e entidades do jogo, depois disso você pode se puxar para esses lugares, alternativamente você pode usar a lingua para balançar, deixando você chegar a lugares difíceis para um humano comum. 
- Pulo alto: Você consegue pular um bloco a mais que um humano comum, pulando 2 blocos no total.
- Super pulo: Você consegue carregar seu pulo agachando, o permitindo performar um super pulo horizontal ou vertical.
